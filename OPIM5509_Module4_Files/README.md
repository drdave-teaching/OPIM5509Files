# OPIM 5509 Module 4 files

Data, saved models and a copy of the notebooks for Module 4 (recurrent neural networks for numeric sequences).

- `notebooks/` - copies of the 13 notebooks used in the Fall 2026 videos. The working copies (the ones HuskyCT and
  the Colab buttons open) live in [OPIM5509-notebooks/Module4](https://github.com/drdave-teaching/OPIM5509-notebooks/tree/main/Module4),
  with a guide to which video uses which notebook. Older notebooks are in `notebooks/_archive/`.
- `data/` - the data files the notebooks load.
- `models/` - saved `.keras` models the part-2 notebooks reload.
